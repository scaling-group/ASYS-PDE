# Public mathematical sources

- Blanchet, Dolbeault and Perthame, Two-dimensional Keller–Segel model:
  optimal critical mass and qualitative properties of the solutions.
  https://www.ceremade.dauphine.fr/~dolbeaul/Preprints/Fichiers/Keller-Segel-30.pdf
  Source for critical mass and radial mass/moment identities.
- Buseghin and Collot, radial Keller–Segel concentration.
  https://arxiv.org/html/2606.20870v1
  The stationary inner core and outer matching do not by themselves solve the
  Gaussian finite-window IVP. Read actual hypotheses before using them.
